# Provenance and licenses

The private workbook names OKSM, ISO 3166, OKATO, OKTMO, FIAS/GAR, Russian standards, IANA TZDB and Natural Earth as sources. It does not provide complete license texts and redistribution evidence for the assembled workbook.

No source dataset is redistributed in this repository. The demo uses invented names, codes and GUIDs. Before publishing any real extract, verify the applicable source version, attribution, redistribution terms and the employer's rights in the assembled data.

No broad license is added to the prepared repository because rights to corporate material and source data have not been established. A license can be chosen later for the newly written code after separating it from all restricted content.
